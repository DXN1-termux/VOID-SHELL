## 🚀 NEW IN V2.0.0

### 🧠 Synapse Vector Store (Semantic Memory)
- **High-Performance Vector Index:** Implemented a local-first Cosine Similarity engine for terminal outputs.
- **Neural Recall:** Use `v recall "query"` to semantically search your entire terminal history.
- **Contextual AI Injection:** The NER engine now uses your session history to provide 10x more accurate fixes.

### 🛰 Specialized Shadow Swarm
- **Scout Worker:** Automated passive recon (IP resolution, DNS mapping) triggered by traffic.
- **Guardian Worker:** Real-time leak prevention. Scans stdout for high-entropy strings and credential patterns.
- **Parallel Orchestration:** Workers run in an asynchronous pool, ensuring zero impact on primary command performance.

### 🌐 Synapse P2P Protocol
- **Intelligence Broadcast:** Instances of VOID-SHELL on the local network now share intelligence beacons via UDP.
- **Remote Sync:** Findings from one device are automatically synchronized to the Synapse DB of peers.

### 🧙 Abyssal Setup Wizard
- **Interactive Bootstrapping:** A high-fidelity setup experience to configure AI providers and shell integration.
